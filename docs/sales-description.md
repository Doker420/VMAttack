# Готовый проект сервиса анонимных посланий 💌

## Короткое описание для объявления

Продаётся готовая основа сервиса анонимных сообщений с сайтом, Telegram-ботом, VK-ботом и Telegram Web App.

Пользователь создаёт персональную ссылку, размещает её в профиле или сторис и получает анонимные послания. Получатель видит сообщения в личном кабинете на сайте, в Telegram Web App и через уведомления ботов.

Проект подходит для запуска собственного сервиса, white-label продукта или быстрого выхода в нишу вовлекающих социальных механик.

---

## О проекте

«Послания» — это сервис, который помогает людям получать честные, тёплые и иногда неожиданные сообщения от друзей, подписчиков и знакомых.

Механика простая:

1. Пользователь входит через Telegram или ВКонтакте.
2. Получает персональную ссылку вида `poslaniya.app/username`.
3. Размещает ссылку в профиле, сторис или личной переписке.
4. Другие пользователи отправляют ему анонимные сообщения без регистрации.
5. Новые послания отображаются на сайте, в Telegram Web App и через VK/Telegram-уведомления.

Проект рассчитан на вирусное распространение: каждый пользователь делится собственной ссылкой и тем самым приводит новых пользователей.

## Монетизация

В проекте уже предусмотрены две платные механики.

### VIP-доступ

```text
20 ₽ на 30 дней
```

Возможности VIP:

- Telegram- и VK-уведомления;
- ежедневные послания;
- расширенный inbox;
- архив и фильтрация сообщений;
- дополнительные функции удержания пользователей.

### Узнать отправителя

```text
7 ₽ за одно послание
```

Платная функция позволяет запросить доступную информацию об отправителе сообщения, если оно было отправлено через Telegram/VK и необходимые данные могут быть раскрыты.

Для веб-сообщений предусмотрена безопасная логика: сервис не обещает раскрытие данных, которых нет или на передачу которых нет согласия.

## Механика удержания пользователей

Для повышения возвращаемости пользователей предусмотрена ежедневная рассылка случайных посланий:

- одно сообщение в сутки;
- случайная фраза из подготовленного набора;
- доставка через Telegram или VK;
- настройка включения/отключения;
- возможность использовать собственные тексты и тематические подборки;
- готовая scheduler-механика для автоматической отправки.

Рассылка работает по opt-in-модели: пользователь сам включает ежедневные послания и может отключить их в любой момент.
