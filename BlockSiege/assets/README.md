# Assets

Модели BLOCKSIEGE не зависят от внешних asset ID. Арена, крепости, персонажи ботов, NPC FORGE/DAILY/ROBUX, лутбокс, косметические эффекты и все семь моделей оружия создаются процедурно из деталей Roblox. Для музыки и SFX используются оригинальные WAV из `audio/`; после загрузки в Roblox их ID нужно вставить в `Config.Audio`.

- `FortressKeyArt.png` — обложка и визуальный референс voxel-направления.
- `Icon.png` — значок для страницы опыта.
- `Thumbnail.png` — миниатюра для страницы опыта.

Перед публикацией загрузите изображения вручную в Creator Dashboard. Они не требуются для запуска `.rbxlx`.

## Audio

- `audio/BlockSiege_Lobby.wav`, `BlockSiege_Build.wav`, `BlockSiege_Battle.wav` — зацикленные темы фаз.
- Остальные 10 WAV — выстрелы, попадания, постройка, разрушение, ядро, кейс, UI, победа и поражение.
- Все файлы: оригинальный детерминированный синтез, 22 050 Гц, 16-bit PCM; музыка stereo, SFX mono.
- `audio/generate_audio.py` — исходник синтеза, `audio/manifest.json` — длительность и контрольные SHA-256.
- Таблица соответствия файлов и `Config.Audio` находится в основном `README.md`.
