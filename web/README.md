# Послания — UI MVP

Интерактивный frontend-прототип сервиса анонимных посланий.

## Запуск

Из корня репозитория:

```bash
python3 -m http.server 4173 --directory web --bind 0.0.0.0
```

Откройте `http://localhost:4173`.

Или запустите любой статический сервер, который отдаёт эту папку. Сборщик и зависимости не нужны: HTML, CSS и vanilla JavaScript специально оставлены простыми для дальнейшего подключения к API.

## Что можно проверить

- «Получить свою ссылку» → введите имя → скопируйте созданную ссылку;
- форма на hero-экране → отправьте тестовое послание;
- «Мои послания» → откройте inbox, увидите счётчики и тестовое сообщение;
- «Подключить Telegram или VK» → сценарии каналов;
- «Подключить тариф» → демо-сценарий оплаты за 199 ₽;
- обновите страницу: демо-сообщения сохраняются в `localStorage`.

Текущие Telegram/VK/CloudPayments в интерфейсе являются сценариями-заглушками. Контракт настоящих webhook/API интеграций и план запуска находятся в [`../docs/anonymous-messages-plan.md`](../docs/anonymous-messages-plan.md).
